# `@runwisp/ui` inventory

Verified against installed `@runwisp/ui@1.7.0` (`README.md`, `package.json`,
`src/lib/index.ts`, and the exported component sources).

## Runtime, stylesheet, and theme

- The package requires Svelte `^5.0.0`; its package description and components
  confirm Svelte 5 runes.
- Styling is built for Tailwind CSS v4. Use `@runwisp/ui/theme.css` as the
  application stylesheet and the Tailwind v4 Vite plugin. Tailwind forms and
  typography plugins are imported by the package stylesheet. Its source files
  must be included with Tailwind `@source` so component utility classes are
  generated.
- `theme.css` imports the plain token sheet, `theme-tokens.css`; that sheet also
  imports the package-shipped TASA Orbiter and Geist Mono fonts. Theme switching
  uses `.dark` on `<html>`.
- The root barrel exports `ThemeToggle`, but **does not export `themeStore`**.
  `ThemeToggle` encapsulates its internal store and offers Auto, Light, and Dark;
  the internal preference is persisted as `runwisp:theme`. Do not deep-import the
  private store. A small pre-paint `app.html` script applies the stored
  preference/system color before styles paint; `ThemeToggle` then owns changes
  and persistence.
- License metadata and the included license are Apache-2.0. Apache-2.0 is
  compatible with this project's GPL-3.0-or-later license.
- All Svelte components and helpers below are imported only from `@runwisp/ui`.
  CSS uses the package's documented `./theme.css` export.

## Foundation shell direction

The shell uses the package palette rather than layering on a second theme:
RunWisp surface `#F3F6F6`, ink `#14262A`, outline `#E0E7E7`, Wisp teal `#0E7C86`,
and Aurora `#15A0A8`; the package supplies its dark equivalents. TASA Orbiter
handles prose and Geist Mono handles the wordmark, navigation, and operational
labels.

```text
┌ Git Clone Manager / Repository operations ───────────────── Theme · account ┐
│ Repositories │                                                │
│              │  Left-aligned page heading                     │
│ list slot    │                                                 │
│              │  ●  Workspace / activity rail                   │
│              │     Main route content                         │
└──────────────┴────────────────────────────────────────────────┘
```

The compact operator shell is preferred to a centered hero or metrics-card
dashboard: the product's job is repository control, and Phase 10 has no real
activity data yet. A small reference-rail mark is the only decorative motif;
status color remains reserved for state, while the repository column becomes a
mobile drawer below 768 px.
